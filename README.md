# ECHO — на одной волне

Сайт запуска: https://rtyty587-cpu.github.io/echo-launch/

Статический сайт с описанием ECHO, интерактивными примерами общения и аур, FAQ и обратным отсчётом до 17 ноября 2026, 00:00 МСК (UTC+3). После даты кнопки ведут к веб-приложению, Android APK и Windows ZIP с EXE.

Дата настраивается в site.js, ссылки — в index.html. Таймер использует часы устройства. Это визуальное открытие кнопок, а не защита файлов: публичный репозиторий и прямые адреса доступны до даты.

Сборка не нужна. GitHub Pages: main, / (root). Все файлы из корня публикуются без приватных ключей. Версия приложений: 1.15.2. Перед обновлением клиентов владельцу Firebase нужно опубликовать отдельный FIREBASE-RULES.txt из комплекта приложения.

Оформление: оригинальный логотип ECHO и сгенерированная иллюстрация. Без внешних шрифтов, аналитики и рекламных трекеров. NFT — внутренние коллекционные предметы. Файлы до 512 КБ, звонки при открытом ECHO.
